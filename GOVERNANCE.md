# OpenRev Project Governance

The OpenRev project operates under a transparent, community-driven governance model.

---

## Roles & Responsibilities

- **Maintainers**: Review pull requests, oversee releases, and vote on RFC proposals.
- **Provider Engineers**: Maintain tool providers (`jadx`, `apktool`, `adb`, `ghidra`, `frida`).
- **Core Engineers**: Maintain execution engine, artifact store, and knowledge graph engine.
- **Contributors**: Submit bug reports, documentation updates, and feature PRs.
